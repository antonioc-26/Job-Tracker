# Job Tracker

A simple web application for tracking job applications during a job search.

Users can add, edit, delete, and filter job applications while tracking their progress through the hiring process.

## Features

- Add job applications
- Edit application details
- Delete applications
- Filter by status
- Dashboard statistics
- Data persistence with localStorage
